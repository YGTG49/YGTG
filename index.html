Gestionnaire d'envoi d'e-mails

Téléchargez un fichier CSV contenant vos destinataires et choisissez un template pour déclencher un envoi via l'API /send.

Utilisez des variables comme ${prenom}, ${entreprise} ou ${email} qui seront remplacées par les colonnes du CSV.

Glissez-déposez un fichier ou cliquez pour sélectionner

Le CSV doit contenir au minimum une colonne email. Les autres colonnes peuvent être utilisées comme variables.
API cible : /send
